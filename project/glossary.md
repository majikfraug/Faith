## Language of the speech (matters for every SUB cue)

The subtitle file is a full transcript: it also captions **English** speech. English speech is never read
(status `skip`, note "English speech"). Only Spanish/Quechua speech gets a subtitle read. The per-block language
check is in `work/sub_language.json` (regenerate with the scratch script if `work/` is lost). In 0:00–5:00 only
1:18–1:54 (the preacher) is Spanish.

**Untranslated Quechua (0:27–1:18, and any later stretch with no subtitles for sighted viewers):** the user has
decided descriptions may go over it, with the voice ducked, because nobody — sighted or not — understands it.
This is the one exception to "never over speech"; note it in the cue when used.

Where the .srt text is itself Spanish (e.g. 8:56–9:21, "Conocí a Romulo…"), the English translation **is** burned
into the picture; the file was simply not corrected there. Read the English off the frames and use it as the line.
