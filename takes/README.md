Your recordings go here (not committed to git). Either:

- one long file, lines read in cue order with a pause of at least a second between them
  (`python ad.py takes --file takes/session1.wav --range 0:00-5:00`), or
- one file per cue, named with the cue id first: `0045.wav`, `0046 church.wav`
  (`python ad.py takes --dir takes/`).
